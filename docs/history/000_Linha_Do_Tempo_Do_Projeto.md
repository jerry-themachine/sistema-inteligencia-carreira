# Linha do Tempo

## Maio/2026 — Origem da Ideia

Durante discussões relacionadas à recolocação profissional, análise de mercado e desenvolvimento de carreira, surgiu a necessidade de criar uma solução capaz de apoiar decisões profissionais através de dados e automação.

A ideia inicial consistia em automatizar a busca e análise de oportunidades de trabalho.

---

## Maio/2026 — Fase Discovery

Foram identificados os principais problemas enfrentados no processo de recolocação profissional:

* Busca manual de vagas.
* Informações distribuídas em múltiplas plataformas.
* Dificuldade de avaliar aderência.
* Falta de indicadores de carreira.
* Ausência de acompanhamento estruturado de competências.

Durante esta fase surgiram os conceitos de:

* Radar de Vagas.
* Score de Aderência.
* Radar de Skills.
* Plano de Desenvolvimento.
* Dashboard Executivo.
* Alertas Inteligentes.

---

## Maio/2026 — Definição do Produto

O projeto evoluiu de uma automação simples para uma plataforma completa de Inteligência de Carreira.

Foi definida a visão do produto baseada em:

* Automação.
* Dados.
* Inteligência Artificial.
* Desenvolvimento Profissional.
* Governança.
