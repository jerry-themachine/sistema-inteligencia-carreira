# Objetivo

Definir padrões de nomenclatura utilizados em documentos, workflows, planilhas, sprints, homologações e artefatos do projeto.

---

# Convenção para Documentos

Formato:

Nome_Do_Documento_vX.Y.md

Exemplos:

Project_Charter_v0.3.md

Architecture_v0.1.md

Workflow_Catalog_v0.1.md

---

# Convenção para Sprints

Formato:

SP-XXX

Exemplos:

SP-010

SP-011

SP-012

SP-013

---

# Convenção para Homologações

Formato:

Nome_Homologation_vX.Y.md

Exemplos:

InfoJobs_Homologation_v0.1.md

Score_v2.1_Homologation_v0.1.md

---

# Convenção para Workflows

Formato:

[FONTE] - [FUNÇÃO]

Exemplos:

INFOJOBS - Coleta

INFOJOBS - Normalização

INFOJOBS - Score

GUPY - Coleta

---

# Convenção para Planilhas

Formato:

snake_case

Exemplos:

vagas_aprovadas

logs_execucao

historico_coletas

---

# Convenção para Commits

Formato:

Verbo + Objeto

Exemplos:

Publish architecture document

Publish workflow catalog document

Publish score homologation document
