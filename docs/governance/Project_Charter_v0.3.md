1. Visão Geral
O Sistema de Inteligência de Carreira (SIC) é uma plataforma em desenvolvimento destinada a apoiar decisões profissionais através da automação da busca de vagas, análise de aderência, identificação de competências demandadas pelo mercado e geração de inteligência para desenvolvimento de carreira.
O projeto também possui caráter educacional e estratégico, servindo como laboratório prático para desenvolvimento de competências em:
•	Gestão de Projetos (PMO)
•	Governança
•	Automação
•	Dados e Analytics
•	Arquitetura de Soluções
•	Inteligência Artificial aplicada
________________________________________
2. Objetivo do Projeto
Desenvolver uma plataforma capaz de:
•	Buscar vagas automaticamente em múltiplas fontes.
•	Consolidar informações do mercado de trabalho.
•	Avaliar aderência entre perfil profissional e oportunidades.
•	Identificar gaps de competências.
•	Apoiar planos de desenvolvimento profissional.
•	Produzir indicadores para tomada de decisão.
________________________________________
3. Objetivos Estratégicos Complementares
Além do produto final, o projeto deverá servir como:
•	Portfólio profissional.
•	Evidência prática para LinkedIn.
•	Evidência prática para currículo.
•	Caso de estudo para entrevistas futuras.
•	Ambiente de aprendizado em PMO.
•	Ambiente de aprendizado em Governança de Projetos.
