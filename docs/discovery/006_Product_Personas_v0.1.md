# Objetivo

Definir os perfis de usuários que poderão utilizar o Sistema de Inteligência de Carreira.

As personas auxiliam na tomada de decisões sobre funcionalidades, prioridades e evolução do produto.

---

# Persona 01 — Profissional em Recolocação

## Nome

Carlos

## Perfil

```text
35 anos
Analista de Dados
Desempregado
Busca recolocação profissional
```

## Objetivos

```text
Encontrar vagas aderentes
Reduzir tempo de busca
Melhorar candidaturas
Monitorar mercado
```

## Dores

```text
Muitas plataformas
Processo manual

Baixa visibilidade de oportunidades
```

## Como o SIC Ajuda

```text
Centraliza vagas
Calcula aderência
Organiza oportunidades
Gera indicadores
```
