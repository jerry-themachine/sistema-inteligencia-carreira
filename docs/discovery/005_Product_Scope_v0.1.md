# Objetivo

Definir formalmente o escopo do Sistema de Inteligência de Carreira, estabelecendo claramente:

* O que faz parte do produto.
* O que não faz parte do produto.
* Funcionalidades futuras.
* Limites do projeto.

Este documento tem como objetivo evitar expansão descontrolada de requisitos (scope creep).

---

# Escopo Atual

O SIC é uma plataforma de inteligência de carreira baseada em automação e análise de dados.

Seu foco principal é apoiar decisões profissionais através da coleta, análise e classificação de oportunidades de trabalho.

# Critérios de Inclusão

Uma funcionalidade poderá ser incluída quando:

```text
Agregar valor ao usuário
Possuir viabilidade técnica
Possuir benefício mensurável
Estiver alinhada à visão do produto
```

---

# Critérios de Exclusão

Uma funcionalidade poderá ser rejeitada quando:

```text
Não contribuir para a missão do SIC
Aumentar excessivamente a complexidade
Não gerar benefício mensurável
Desviar do objetivo principal
```
