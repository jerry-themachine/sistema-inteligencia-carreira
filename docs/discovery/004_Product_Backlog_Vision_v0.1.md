# Objetivo

Definir a visão de longo prazo do backlog do produto, consolidando funcionalidades futuras, prioridades estratégicas e direcionamento evolutivo do SIC.

Este documento complementa:

* Origem do Projeto
* Definição do Produto
* Evolução do Produto
* Roadmap

---

# Visão Estratégica

O SIC deve evoluir de uma ferramenta de automação de busca de vagas para uma plataforma completa de inteligência de carreira baseada em dados.

---

# Pilar 01 — Radar de Vagas

## Objetivo

Centralizar oportunidades profissionais em um único ambiente.

### Funcionalidades Atuais

```text
Arbeitnow
Gupy
InfoJobs
```

### Funcionalidades Planejadas

```text
Recrutei
Catho
LinkedIn
Indeed
Glassdoor
Vagas.com
```

### Prioridade

Alta


# Visão de Futuro

O SIC deverá evoluir para uma plataforma capaz de:

```text
Buscar oportunidades
Analisar mercado
Recomendar ações
Monitorar evolução
Apoiar decisões profissionais
```

de forma automatizada e orientada por dados.
